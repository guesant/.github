# .github

Shared GitHub community health files and repository defaults for projects under [`guesant`](https://github.com/guesant).

This repository contains common contribution, support, security, funding, issue, and discussion templates used as defaults across repositories that do not provide their own versions.

Repository-specific files take precedence over the defaults defined here.

## Files

### [CONTRIBUTING.md](CONTRIBUTING.md)

General contribution guidelines.

Covers topics such as:

* Opening issues and feature requests.
* Preparing pull requests.
* Testing and documentation.
* Code style and compatibility.
* Dependencies.
* AI-assisted contributions.
* Licensing and review expectations.

Individual repositories may provide additional or more specific contribution requirements.

### [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

Expected standards of behavior when participating in project spaces such as issues, pull requests, discussions, and reviews.

### [SECURITY.md](SECURITY.md)

Default security policy.

Describes how to report suspected vulnerabilities privately and what information should be included in a security report.

Security vulnerabilities should not be disclosed through public issues, discussions, or pull requests.

### [SUPPORT.md](SUPPORT.md)

General guidance for requesting help.

Explains where to ask questions, what information is useful when requesting support, and how Issues, Discussions, feature requests, and security reports should be used.

### [.github/FUNDING.yml](.github/FUNDING.yml)

Default funding configuration for repositories that support sponsorship.

### [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/)

Default issue forms.

Current forms include:

* [bug.yml](.github/ISSUE_TEMPLATE/bug.yml) for reproducible bugs.
* [feature.yml](.github/ISSUE_TEMPLATE/feature.yml) for concrete feature requests.
* [config.yml](.github/ISSUE_TEMPLATE/config.yml) for issue creation settings and additional support links.

Questions and exploratory discussions should generally use GitHub Discussions when available.

### [.github/DISCUSSION_TEMPLATE/](.github/DISCUSSION_TEMPLATE/)

Default forms for GitHub Discussions.

These may include categories for:

* General discussions.
* Questions and answers.
* Ideas and early-stage proposals.

## Repository-specific policies

These files are intended to provide sensible defaults rather than impose identical processes on every project.

A repository may define its own versions of these files when it requires different:

* Contribution workflows.
* Development requirements.
* Security procedures.
* Support channels.
* Issue forms.
* Discussion categories.

When repository-specific instructions exist, follow those instructions.

## Questions and support

For questions about a specific project, use that project's support channels rather than opening an issue in this repository.

See [SUPPORT.md](SUPPORT.md) for general guidance on requesting help.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md).
